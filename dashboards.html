ADHMAT dashboards

Two interactive views. Please read how each one treats data.

National

National dashboard

Shows maturity level, domain results and regional views from a REDCap export.

  • Load a CSV exported from REDCap, or try the built-in sample
  • The file is read in your browser. This site does not upload it anywhere
  • Needs an internet connection to load its chart libraries
Open the national dashboard
Test data · REDCap import

Continental insights

A continental view of the State of Digital Health for all 55 Member States, with a map, domain views and filters.

  • Opens with generated test data, clearly labelled. Do not read it as real country results
  • Import a REDCap export (CSV or JSON): it is checked, then stored in your browser
  • Ready for a scheduled REDCap feed that refreshes the dashboard on an agreed timetable
Open the continental dashboard
Data protection. Do not load patient-level or confidential data into any public website. Use aggregated assessment results only.
